# 💰 QuincenaApp

**Control de gastos quincenal** — Una aplicación web para llevar el registro de gastos de tu salario por quincenas.

## ✨ Funcionalidades

### 👤 Multi-usuario
- Crear, seleccionar y eliminar usuarios
- Cada persona tiene sus propios datos separados

### 📅 Gestión de Quincenas
- Registrar el ingreso de cada quincena
- Cerrar quincena para moverla al historial
- Navegación entre quincenas activas e históricas

### 🏦 Control de Deudas
- Agregar deudas con nombre, monto total adeudado y monto por quincena
- Pago **completo** o **parcial** (con monto manual)
- El saldo restante se actualiza automáticamente
- Opción de deshacer pagos en caso de error
- Adjuntar comprobantes/capturas de SINPE o pagos

### 🛒 Gastos Adicionales
- Registrar compras y gastos no relacionados a deudas
- Se descuentan del balance disponible en tiempo real

### 📊 Balance en Tiempo Real
- Vista de ingreso, gastado y disponible
- Barra de progreso visual
- Alerta visual (rojo) cuando te excedes del presupuesto

### 📋 Historial
- Ver todas las quincenas cerradas
- Detalle completo de cada quincena con deudas y gastos

### 📥 Exportación
- Formato CSV o PDF
- Por quincena actual, mes, o rango personalizado
- Incluye comprobantes adjuntos en el reporte

## 🚀 Uso

1. Abrí `index.html` en tu navegador
2. Creá un usuario
3. Registrá tu quincena (monto de ingreso)
4. Agregá tus deudas y gastos
5. ¡Listo! Llevá el control de tus finanzas 💪

## 🛠 Tecnologías

- HTML5
- CSS3 (variables, grid, flexbox, animaciones)
- JavaScript vanilla (ES6+)
- localStorage para persistencia de datos
- Sin dependencias externas

## 📱 Responsive

Funciona en desktop, tablet y celular. Diseñada con un enfoque mobile-first.
